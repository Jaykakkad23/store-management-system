# Stock Shift

Stock Shift is a browser-based store management app for owners and cashiers. Owners can monitor sales, manage inventory, track low-stock and near-expiry products, and review shifts. Cashiers can process sales and handle shift handovers.

## About

Stock Shift is a simple website project for managing a small store. It has two types of users: owner and cashier.

## Features

### Owner
- View today's sales and stock information
- Add or edit products
- Search inventory
- View sales reports
- Export sales data as a CSV file
- Start and close shift records
- Find low-stock and near-expiry products

### Cashier
- Start a new shift
- Search and add products to the cart
- Complete sales
- View inventory
- Close the shift and enter the counted cash

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No database or server setup is required.

or just go to "https://stock-shift.vercel.app/"

## Technologies Used

- HTML
- CSS

## Data Storage

The project stores product, sales, and shift data in the browser using localStorage. Demo data is loaded when the project is opened for the first time.
